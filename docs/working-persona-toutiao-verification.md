# 工作画像恢复与今日头条登录修复（2026-11-21）

基线：492ae4600ebfa95dcd8530c38e8c26efb0bd963f。个人专业工作台修复，不改变项目、对话、版本或平台账号的数据归属。

## 工作身份流程

- 单独持久化当前工作画像；未选择（null）与明确选择通用模式（空字符串）区分。
- 已有有效选择优先；旧版本无独立选择时默认唯一画像，多画像时可从上次有效活跃对话迁移；没有有效依据才要求选择。
- 画像列表失败或格式异常不清除原选择；确认画像已删除时安全降级，不重写历史对话。
- 工作页面顶部显示当前工作画像、切换器及管理入口。切换留在当前页面，不新建会话、不调用模型。
- 打开、归档、删除或恢复历史对话不覆盖工作画像。聊天单独显示该对话的固定身份；明确进入关联项目时显示该项目归属。
- 画像管理使用“设为当前工作画像／当前使用中”文案；查看编辑与选择工作身份分开。
- 首页灵感、内容排期、项目按当前画像统计；未归属灵感和排期单列提示。平台活动不算内容待发排期；账号与最近文件明确为全局。
- 加载中、加载失败、未选择不冒充数字0；总排期数量与前五条预览仍分开。

## 今日头条根因与修复

真实保存会话可进入头条号后台，但第三方客服 iframe 的“请输入手机号方便联系（非必填）”字段被旧检测当成登录手机号绑定，后台因此一直停留在等待验证，最后超时。真实账号区的新选择器也不在原匹配范围。

修复：
- 登录挑战仅在主页面与明确官方认证 iframe 中检测，客服表单不参与登录判定；真正官方手机号／密码／验证码挑战仍阻断认证。
- 认证成功仍要求正确官方后台、有效会话及可见创作者控件；不是只看URL或忽略错误。
- 匹配当前后台账号区域。等待SPA就绪；不为确认登录反复导航用户页面。
- 观察同一浏览器上下文中仍存活的官方标签，处理SSO替换标签；允许明确的官方认证中转，不把认证中转当登录成功。其他域名及HTTP不借用。
- 页面关闭不继续盲目等待原标签；异常日志记录阶段、类型和栈位置，不打印Cookie、验证码或SSO查询参数。成功状态在会话关闭保存完成后写入。
- 失败弹窗增加“已登录？重新核验”，只核验现有会话，不自动重启登录。核验未知保留原状态；关闭弹窗后迟到结果不复活弹窗。
