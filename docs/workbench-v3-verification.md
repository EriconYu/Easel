- 存储使用重入锁、唯一临时文件、fsync及原子替换；损坏文件明确报错，不默默覆盖。

## 实际运行验收

本机实际启动个人工作区后，在浏览器完成以下操作；验收记录仅保留于本地缓存，不提交私人文稿或运行数据。

1. 从对话原话创建两条明确标注为验收用途的灵感，不冒充用户历史爆款。
2. 在第二条灵感中显式检索并选择第一条，验证原话与引用进入服务端生成上下文。
3. 使用真实模型完成口播生成，检查正常结束标志及实际正文；通过界面取回正文并保存版本。
4. 修改来源备注并取消本次引用，读回旧版本，确认原话和旧引用快照未变。
5. 重启后通过API再次读回同一原话、版本与已取消的引用状态，结果保持一致。
6. 在热点雷达的普通创作讨论中选择、保存、取消历史灵感，服务端读回正确。
7. 热点真实搜索、AI分析、带来源生成、版本读回与原始来源导入已完成独立运行验收。

首次生成暴露了运行配置问题：全局Codex默认模型被供应端报告不可用。只将Easel私有运行配置选为先前已成功的模型，未修改全局Codex配置，也未将个人配置提交。随后在原会话中真实生成成功。失败回复不会被“取回稿件”当成成功正文。
