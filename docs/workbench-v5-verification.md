| 评审项 | 修复与回归覆盖 |
|---|---|
| 1 私有配置读取 | 通用读取/下载/归档拒绝内部目录、旧 analytics/wechat 与符号链接；二维码和人工包使用限定类型的交付接口，不开放私有目录。保护不可变版本及父目录的删除。 |

| 3 日历写入协议 | Web、CLI、publisher 共用跨进程可重入锁、损坏拒写、唯一临时文件与原子替换。 |

| 6 实际稿预检 | 对各平台有效正文、标签、素材与来源冻结快照，检查和提交使用同一载荷；等待时编辑/换画像会取消提交。 |
| 7 稿件依据 | 保存来源版本或真实轮次ID；生成输入快照不可变；声明依据与已知输入分开。失败/取消轮次不能静默成为后续可信历史。旧轮次无快照明确未核验。 |

| 10 排期编辑去重 | PUT 与 POST 使用同一身份规则，锁内排除自身查重，冲突409。 |
| 11 关联归因 | 关联/非关联共享发表归因；按执行而非正文识别回执；归因记录写入有跨进程锁，目标跟随日历目录。多候选提交前拒绝歧义，执行后新生歧义不新建排期且明确警告。 |
| 12 最近产物 | 携带明确路径进入文件视图，不再只跳内容库并显示旧项目。 |
| 13 技能生命周期 | 详情、配置保存与执行请求分离；旧请求不能吞结果或卡住执行状态。 |
| 14 小红书退出 | 按当前生效 native/manual 模式处理，历史手动记录不能阻挡原生退出。 |
| 15 主模型端点 | 结合持久有效端点识别唯一主槽，而非同 provider/model 两行同时标主。 |
| 16 拆解归档 | 成功/失败分离；仅成功结果可归档，保留完整输入原文、画像和摘要。 |
| 17 首页计数 | 总数与前五条预览分别计算。 |
| 18 平台能力 | 共享前端能力表与后端一致性测试；区分创作、排期、人工交付、自动提交，微博不伪称支持集成。 |

## 复审补修

- 发布适配中载入另一项目必须失效旧流；迟到 token 不得混入新项目来源。
- 仅修改创作依据或灵感引用也属于未保存修改，切版本不得静默覆盖。
- 登录二维码和人工 ZIP 的专用交付保留原功能；公开项目中的下划线媒体仍可用，系统目录仍隔离。
- 自动发表成功与日历回填成功分别表达；回填失败不能诱导用户重复发表。

## 验收边界

测试使用临时目录、合成模型/平台响应与独立浏览器存储；没有真人发文、代扫码、修改 Cookie 或下载新依赖。单元/组件测试不是实际平台发表证明。

真实页面验收：正文切页与刷新恢复、取消历史覆盖保留正文、未发送聊天输入恢复；为选中已有历史稿，仅对隔离浏览器的 GET 响应排序，不修改服务端任务。首页计数使用八条合成排期；十页面只读遍历检查 JavaScript 错误。

不提交 outputs、画像、登录态、Cookie、密钥、私人稿件或验收缓存。受保护的“照片”“把紫微斗数算一遍”文件以既有739项哈希与 inode 基线核验。
